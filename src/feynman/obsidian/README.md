# Obsidian 插件开发

这里记录 Obsidian 插件开发的相关内容。所有插件均已上架 [Obsidian 社区市场](https://obsidian.md/plugins)，在 Obsidian 设置 → 第三方插件 → 浏览中搜索 **fengshuzi** 或对应插件名称即可安装。
